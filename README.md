# LankaMacro AI

Sri Lankan economic research, built around traceable official evidence.

**Team:** Akinda Gunarathne and Sachin Gimahana.

The first implementation milestone is being added: a Next.js research workspace, FastAPI evidence API, reviewed inflation charts, a source library, and an inflation-adjusted return calculator.

This project is an independent project. It is not affiliated with the Central Bank of Sri Lanka or the Department of Census and Statistics.
